# QA fixes — 23 September 2026

This implements the fixes from the 22 September review against the current Svelte app. Existing branding and previously committed account changes are preserved.

## Changes

- Timer checkpoints persist on meaningful actions rather than every tick. Reload restores elapsed countdown time (bounded by the interval end), pauses recovery for explicit resumption, and preserves credited hours without counting them again. Stopwatch recovery is bounded to 24 hours. Pending network writes still require keeping the tab open; no browser-storage fallback was introduced.
- Version conflicts return authenticated, structured server progress. Independent notes and checklist edits merge; competing edits require choosing between visible versions. Timer, selected day and credited hours are resolved together to avoid double credit. Draft downloads include local, remote, merged and unresolved versions.
- Focus Mode preserves button keyboard activation, exposes checkbox names/state, includes full part descriptions and interval selection, and supports session completion. Background controls are inert while Focus is open. Empty reference space is reduced, mobile content scrolls, and save errors remain visible inside Focus.
- Phone and portrait-tablet layouts put the single timer ahead of lesson cards, notes and completion actions.
- Vite now keeps port 5173 fixed. Google Cloud inspection confirmed the existing client already authorizes `http://localhost:5173` and the production domain, but not `http://127.0.0.1:5173`. Use the authorized localhost address. No Google OAuth settings were changed.
